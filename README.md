# Jawabu Beauty Shop

Customer shop and staff admin for Sleek Sisters. Both apps use Supabase.

- Storefront: `frontend`
- Staff app: `jawabu-admin`
- Database snapshot and SQL history: `supabase`
- Old unused API: `backend` (do not run it against Supabase)

```bash
npm run dev:frontend
npm run dev:admin
```

Copy `frontend/.env.example` and `jawabu-admin/.env.example` to `.env` files with the Supabase URL and publishable key before starting either app.
